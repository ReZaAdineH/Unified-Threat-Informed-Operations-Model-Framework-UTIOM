# UTIOM Ecosystem Wiki

This directory is the **human-friendly ecosystem map** for UTIOM and its related public models, context services, assessment resources and community channels.

It is intentionally different from the technical documentation in [`docs/`](../docs/):

- **`docs/`** explains the framework in depth and mirrors the canonical public knowledge surface.
- **`wiki/`** explains how the ecosystem fits together, where to go for each topic, how to participate, and how the ecosystem may evolve without changing the canonical UTIOM lifecycle by accident.

The canonical UTIOM framework remains defined by https://utiom.de and the versioned public documentation in this repository.

## Core rule

> **UTIOM defines the operating model. Supporting models measure capability depth or add decision context. They do not become additional UTIOM lifecycle phases.**

## Authority and change control

The wiki is an orientation and community layer. If any wiki wording conflicts with the current canonical UTIOM site, versioned framework documentation or model definitions, the canonical source wins and the wiki should be corrected.

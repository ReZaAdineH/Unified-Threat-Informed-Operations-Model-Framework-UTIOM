# UTIOM in One Minute

**UTIOM stands for the Unified Threat-Informed Operations Model.** It is a lifecycle operating model for Security Operations that connects business purpose, relevant threats, engineering, response and measurable improvement.

The seven phases are:

1. **Vision** — define why Security Operations exists, what must not fail and how success will be measured.
2. **Strategy** — turn purpose into operating priorities and a documented Threat Profile.
3. **Crown Jewels** — identify critical services, dependencies, trust boundaries and realistic attack paths.
4. **Threat Visibility** — engineer and assure the telemetry required to observe important adversary behaviour.
5. **Threat Detection** — build versioned, testable, threat-informed detections from attack paths and available evidence.
6. **Response** — analyse, decide and act with prepared authority, playbooks and containment options.
7. **Continuous Improvement** — use incidents, validation and metrics to improve Strategy and engineering.

Three pillars organise the work without creating silos:

- **Leadership & Governance**
- **Engineering & Enablement**
- **Operations & Analysis**

The core logic is:

**Purpose → relevant threats → attack paths → evidence → telemetry → detection → response → measurement → improvement**

And the operating cycle is:

**Assess → Prioritise → Engineer → Validate → Measure → Improve → Assess**

UTIOM treats Security Operations as a living product and treats Incident Response as the operating mode of Security Operations rather than an isolated final phase.

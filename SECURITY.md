# Security Policy

## Scope

This repository contains public UTIOM framework documentation and selected public artifacts. It is not the production application repository.

## Reporting a security concern

Do **not** publish sensitive security findings in a public GitHub issue.

This includes suspected vulnerabilities affecting:

- UTIOM production services;
- authentication or authorization mechanisms;
- infrastructure or deployment configuration;
- credentials, tokens, secrets, or environment variables;
- administrative interfaces;
- internal APIs;
- private repositories or non-public implementation details.

If a finding concerns only a documentation error, broken public link, typo, or non-sensitive framework inconsistency, a normal GitHub issue is appropriate.

For sensitive matters, use the security contact method published on the official UTIOM website: https://utiom.de

## Public/private boundary

The fact that UTIOM is publicly documented does not mean its production source code, deployment architecture, private automation, credentials, internal APIs, or other operational implementation details are public.

Please do not submit or request disclosure of private implementation material through this repository.

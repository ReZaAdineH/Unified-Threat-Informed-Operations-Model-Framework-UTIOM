# UTIOM Public Release History

UTIOM is a living framework. This changelog records public framework releases and material documentation changes.

## v1.1 — August 2026

- Published the public assessment instruments for maturity, capability and metrics.
- Added the combined improvement-roadmap workflow and offline/self-hosted assessment options.
- Strengthened validation and adversary emulation as first-class operational capabilities.
- Extended automation across applicable lifecycle phases.
- Expanded measurement so Vision, Strategy and Crown Jewels are instrumented rather than treated as unmeasured preparation activities.
- Continued refinement of the framework documentation and ecosystem alignment.

## v1.0 — February 2026

- First public edition of the UTIOM framework book.
- Published the full lifecycle and capability-layer model.
- Introduced the threat-informed maturity model.
- Published the implementation blueprint and initial metrics.
- Included worked examples across cloud-native, hybrid banking and OT/manufacturing scenarios.

## Repository publication — August 2026

- Established this repository as the public UTIOM framework and community repository.
- Added citation metadata, public security-reporting guidance and contribution rules.
- Explicitly separated public framework material from private production implementation and deployment code.

The canonical website remains https://utiom.de.

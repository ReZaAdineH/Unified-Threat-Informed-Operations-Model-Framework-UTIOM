# UTIOM public downloads

Canonical downloadable binaries are hosted on **utiom.de**. This public repository indexes those artifacts and contains framework documentation, diagrams and limited self-hosting/bootstrap configuration.

## Current public versions

| Artifact | Version | Official location |
| --- | --- | --- |
| UTIOM framework / website | **v1.4** | https://utiom.de |
| Assessment workbook | **v1.4** | https://utiom.de/utiom-assessment-workbook.xlsx |
| Self-hosted toolkit | **v1.4** | https://utiom.de/utiom-assessment-toolkit-v1.4.zip |
| UTIOM Framework Book | **v1.2** | https://utiom.de/downloads/UTIOM-Framework-v1.2.pdf |

The generic toolkit link may also point to the current package, but the versioned v1.4 filename is preferred for release integrity.

## Version relationship

Framework/methodology, workbook and toolkit are v1.4. The Book remains edition v1.2 intentionally.

## Integrity

Checksums for the most recently verified downloadable artifacts are recorded in [`CHECKSUMS.sha256`](CHECKSUMS.sha256). When a packaged artifact changes, including a licensing-file change inside a ZIP, its checksum must be regenerated rather than reused.

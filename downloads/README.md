## Book edition note

The **current published book is v1.1**. The UTIOM framework and assessment toolkit have continued to evolve to v1.3, and a **new edition of the book is in preparation and will be published soon**.

Keeping the book at v1.1 here is deliberate; the repository must not mislabel the existing book as v1.3.

## Workbook

The v1.3 workbook contains the public offline assessment material across:

- Read me
- Maturity
- Lifecycle
- STRATA
- Capability
- Metrics

## Self-hosted toolkit

The complete v1.3 package includes the static public site and assessment instruments together with Docker/nginx configuration for running the toolkit locally. The Docker bootstrap files are also documented under [`../self-hosted/`](../self-hosted/).

## Public-use commitment

These artifacts are part of the intentionally released public/community edition of UTIOM. Future commercial or enterprise offerings may add services, automation, integrations, collaboration, assurance and other capabilities, but they do not retroactively remove the rights granted for material already released publicly under its stated licence.

See [`../PUBLIC-COMMERCIAL-BOUNDARY.md`](../PUBLIC-COMMERCIAL-BOUNDARY.md) for the project boundary.
